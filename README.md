## 👟 Nike Brand Page

**Description:**  
A clean and modular **Nike-themed brand landing page** built using **React.js**. This project focuses on component-based architecture and establishes a foundation in modern frontend practices. It serves as an introduction to creating reusable UI components and organizing code efficiently in a React application.

🔗 **Live Demo**: [Website Link](https://brand-page-nike-five.vercel.app/)
📱 *Note: Not fully responsive yet; layout may break on smaller screens.*

---

### ✅ Features

- Responsive brand landing page layout  
- Navigation bar and hero section built as separate components  
- Clean modular structure (no monolithic HTML files)  
- Organized JSX and styling for easier maintenance

---

### 🛠️ Tech Stack

- **React.js** – UI development with component-based structure  
- **JavaScript (ES6+)** – Interactivity and structure  
- **CSS** – Styling and layout

---

### 📘 Key Concepts Applied

- Project initialization using `npm create vite@latest`  
- Component creation and reuse  
- Proper use of `className` instead of `class` in JSX  
- Basic use of `npm` for package management  
- File and folder structure best practices in React

---

💡 _This project helped lay the groundwork for future React development by focusing on structure, reusability, and clean coding habits._
